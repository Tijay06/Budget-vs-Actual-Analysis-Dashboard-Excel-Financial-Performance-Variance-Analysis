
#  Budget vs Actual Financial Analysis | Interactive Excel Dashboard

An interactive **Financial Analysis Dashboard built entirely in Microsoft Excel** to compare budgeted versus actual financial performance using a dataset containing **10,000+ records**. This project includes data cleaning, financial variance analysis, KPI development, PivotTables, PivotCharts, interactive slicers, and advanced Excel dashboard formatting.

The dashboard helps analyze departmental performance, regional financial trends, monthly financial movements, category-wise expenses, payment methods, and budget utilization.

##  Project Overview

The objective of this project is to transform raw financial data into an interactive reporting solution that enables users to monitor financial performance, identify budget deviations, and compare actual expenses against planned budgets.

The project demonstrates practical expertise in **Advanced Excel, Data Cleaning, Financial Analytics, Data Visualization, and Business Intelligence**.
